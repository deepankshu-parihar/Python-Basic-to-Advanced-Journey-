   →Project Explanation:
     ★Number Guessing game:-
        In this game ,the computer generates a    random number between 1 and 100, and the user tries to guess the correct number.
 
     »Function/Libraries used:
      •import random:import a random number library
      •random.randint():generate random integer between the give range
      •While Loop: Repeats the game until the correct number is guessed.
      •If-Else Statements: Check whether the guess is too low, too high, or correct.
      •User Input: Accepts guesses using input().
      •Variables: Store the random number, guess, and number of attempts.
     »How to Run
      •Install Python on your computer.
      •Download or clone this repository.
      •Open the project folder in VS Code or a terminal.
      •Run the following command:
        python main.py

     »Example Output
       Guess a number (1-100): 50
       Too low! Try again.
       Guess a number (1-100): 75
       Too high! Try again.
       Guess a number (1-100): 63
       Congratulations! You guessed it!
       Attempts: 3

      »Purpose
        This project was created for practising basic Python programming concepts, including loops, conditional statements, user input, and random number generation.
